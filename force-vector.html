🧮 วิธีคำนวณแรงลัพธ์

ระบบจะแสดงแนวคิดการรวมแรงเป็นขั้นตอน

1
รวมแรงในแกน X

ΣFx = F1x + F2x + F3x

2
รวมแรงในแกน Y

ΣFy = F1y + F2y + F3y

3
รวมแรงในแกน Z

ΣFz = F1z + F2z + F3z

4
หาแรงลัพธ์

|ΣF| = √(ΣFx² + ΣFy² + ΣFz²)

5
ตรวจสอบสมดุล

ถ้า |ΣF| ≈ 0 ระบบจะอยู่ในสมดุล

📐 สูตรสำคัญ

ΣF = F₁ + F₂ + F₃ ผลรวมของแรงทั้งหมด
ΣFx = F₁x + F₂x + F₃x องค์ประกอบของแรงในแกน X
ΣFy = F₁y + F₂y + F₃y องค์ประกอบของแรงในแกน Y
ΣFz = F₁z + F₂z + F₃z องค์ประกอบของแรงในแกน Z
|ΣF| = √(Fx² + Fy² + Fz²) ขนาดของแรงลัพธ์
F̂ = F / |F| เวกเตอร์หนึ่งหน่วย
